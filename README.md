## 📌 如何在 GitHub 仓库主页配置专属独立链接？

你有 **3 种最推荐的方式** 将这个主页绑定到你的 GitHub 上：

### 方案 1：在 GitHub 仓库主页右侧添加「About 专属网站链接」（10 秒搞定，最直观）
1. 打开你在 GitHub 上的本仓库页面（例如 `https://github.com/你的用户名/仓库名`）。
2. 在仓库主页右侧边栏，找到 **About** 区域，点击右侧的 **⚙️ 小齿轮（Edit repository details）**。
3. 在弹出的窗口中：
   * **Description**: 输入简介（例如：`Millen Woods Mariners 40-Week Grade 4 Math & Global Explorer App by Yang & Melody`）
   * **Website**: 粘贴专属在线地址：  
     `https://ais-pre-l6t452gmoqyhwv2dipdyhq-172462247321.us-west2.run.app`
   * 点击 **Save changes** 保存。
4. **效果**：任何人访问你的 GitHub 仓库，在右上角就能看到一个高亮的网页图标和直接跳转的专属主页链接！

---

### 方案 2：开启 GitHub Pages 专属子域名（`username.github.io/repo`）
项目中已为您内置好了 `.github/workflows/deploy.yml` 自动化工作流与 Vite 相对路径配置：
1. 在 GitHub 仓库页面，点击上方的 **Settings**（仓库设置）。
2. 在左侧菜单栏点击 **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 下拉菜单中，选择：
   👉 **`GitHub Actions`**。
4. 随后每次您 `git push` 代码到 `main` 分支，GitHub 就会自动为您构建并发布专属域名：
   `https://<你的GitHub用户名>.github.io/<仓库名>/`

---

### 方案 3：关联 Vercel / Netlify（免费拥有独立自定义域名）
如果你想拥有极简短网址（例如 `millen-mariners.vercel.app`）甚至绑定自己的专属独立域名：
1. 访问 [Vercel](https://vercel.com) 并使用 GitHub 账号登录。
2. 点击 **Add New Project** -> 选中你刚 push 的这个 GitHub 仓库。
3. Framework Preset 选择 **Vite**，点击 **Deploy**。
4. 1 分钟后即可获得一个专属的永久 `.vercel.app` 短链接，还可以在 Settings -> Domains 里免费绑定任何个人域名！

## 🌟 核心特色功能 (Features)

* **📐 40 周 WRDSB 安省官方四年级数学探险**：
  * 每周 5 题渐进通关机制（基础稳固 ➔ 核心进阶 ➔ 挑战冲刺 ➔ 终极奥数/思维脑王）。
  * 支持 4 档难度自主筛选（Easy / Medium / Hard / Olympiad）。
  * 🎲 **动态变式题生成器**：数字随机变化，告别死记硬背。
  * 🏆 **全屏沉浸式胜利庆典**：3D 动态金宝箱爆开、胜利礼花与勋章评定。
* **🌍 世界知识护照 (World Explorer)**：
  * 覆盖全球各大洲国家（中国长城、加拿大枫叶红雀、秘鲁马丘比丘、印度、肯尼亚、南极洲等）。
  * 精致手绘矢量插画与徽章，中英双语科普。
* **🎨 创意草稿画板 (Scratchpad)**：
  * 自由手绘、网格点阵底纹、数学几何尺规工具。
* **🔊 多模态音效与朗读**：
  * 题目英/中语音朗读、宝箱音效、金币音效。
* **👨‍👩‍👧 创作者致敬**：
  * Created with ❤️ by Yang & Melody.
